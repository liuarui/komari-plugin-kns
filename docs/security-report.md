# 安全评估（本地代码审查）

## 范围

评估 KNS 1.0.0 源码、远程执行脚本构造、历史节点只读发现/导入、批量扫描、回调、订阅和本地状态存储，并复核外部 SubConverter 的 HTTPS 限制及加密备份导入中断恢复。本报告不是渗透测试或完整线上审计证明。

## 控制措施

- **远程安装授权**：机器远程安装权限默认开启，首次升级时会先备份存储，再一次性启用已有机器；管理员可在机器卡片逐台关闭。权限开启不会自动执行命令，安装任务仍需管理员在管理页主动提交；新探针自动部署是独立设置，默认关闭。危险远程操作要求管理员、明确 `confirm:true` 和幂等键。管理页不要求输入 2FA；服务端仍兼容 API 调用方传入 Komari 2FA。
- **远程执行完整性**：执行 OneBox 安装脚本前从固定 commit URL 下载并核对 SHA-256；请求 JSON 先落入目标机 root-owned、mode 0600 的受保护临时目录，再由 OneBox schema 校验。
- **安全卸载**：卸载前必须通过 Agent 读取 OneBox 当前配置引用图；管理页展示仅删除本实例的资源、保留共享引用，以及重载共享服务的影响。状态预览不完整或超过 5 分钟即拒绝提交卸载。
- **双重结果核对**：一次性 job token 绑定 job/machine/runtime/version；需要 Agent 退出码和 `onebox kns status` 同时吻合。
- **历史节点导入**：发现只保存协议/监听元数据；管理员点击明确的“纳入管理并加入订阅”按钮后提交，服务端要求在线机器、30 分钟内扫描结果和一次性 HTTPS 回调。导入节点标为外部只读，不能由 KNS 停用、重配或卸载。
- **秘密保护**：实例凭据、旧版 OneBox URI、订阅 token 和派生订阅正文快照以明文保存在权限 `0600` 的插件存储中；不再依赖 master key。订阅 token 仍使用随机 256-bit 值和随机 salt + SHA-256 hash 校验；明文 token 仅用于管理员重复查看。`/admin/state` 和审计日志不返回 token 密文或明文；`profile.token.show` 等管理响应设为 `no-store`。回调 token hash 在首个有效回调后删除；同 body digest 重试可幂等返回 204。
- **路由/输出**：管理路由检查 admin principal；写路由接受同主机 HTTPS Origin、管理员设置的公网 HTTPS Origin，或 HTTPS `Sec-Fetch-Site: same-origin` 元数据（适配反代 Host 改写），不会信任任意转发头；跨站 Origin 仍拒绝。订阅接口可按档案设置是否校验 token；关闭后 URL 即持有访问权。状态 API 和日志不会返回 credential ciphertext 或远端输出全文。订阅响应 `no-store`。
- **状态文件**：state 与订阅快照临时文件在原子替换前执行 `fsync`；state/订阅快照文件设为 0600，目录 0700；state 保留滚动快照并支持恢复，订阅正文缓存可从 state 重建。master key 仅用于兼容旧密文和口令加密导出。
- **升级与旧数据迁移**：插件版本变更及迁移旧版 `onebox-bridge.json` 前先私有复制整个插件存储目录；备份暂存目录保持在 Komari 授权的 `__storageDir__` 内，并排除自身，避免越界和递归复制。备份失败或状态来自更新版本时停止加载，不写入状态；升级错误会显示截断清理后的原因。
- **离线导出与恢复**：原始 JSON 下载路由已关闭。管理员从受信 Origin 写路由创建独立口令加密包；PBKDF2-SHA256 派生 AES-256-GCM 密钥，密文包含 state 和恢复用 master key（兼容旧密文），口令不持久化。导入先校验 AEAD 与 schema，再备份本地 state/key；宿主注入 key 时拒绝不匹配的包。
- **并发/DoS 限制**：旧节点只读扫描最多选择 100 台在线探针，并最多同时提交 5 个单机扫描请求；端点与健康探测最大并发 5，KNS 对同一探针的 OneBox 远程任务互斥，每轮最多查询 20 个任务；请求正文上限 1 MiB；token 比较使用常数时间字节比较。
- **交互并发控制**：Schema 2 管理写请求可用 `expectedRevision` 拒绝旧草稿覆盖；批量部署按目标 UUID 和稳定 batch ID 做幂等复用；安装结果超时后的管理页先查询同一批次。备份恢复前检查活动任务，并在本进程持有维护锁。

## 已知限制与风险

1. 安装器以 root 在探针执行。SHA pin 降低供应链漂移，但任何 OneBox 脚本变更都要求审查并更新 commit + SHA。
2. 外部 SubConverter 默认关闭。KNS 只接受显式配置的 HTTPS `/sub` 地址；旧状态中即使保留历史 HTTP 地址，生成链接时也会再次校验并返回空值。启用受信 HTTPS 转换器时，它仍会收到含订阅 token 的源 URL 和转换后的节点凭据，必须信任该服务运营方；订阅 token 也可能进入代理访问日志。
3. `KNS_MASTER_KEY` 环境变量由宿主配置管理；若未设置，自动生成的 key file 必须和状态备份一起保管。日常滚动状态备份包含明文凭据和令牌，必须按敏感数据保管；离线加密导出口令不可找回。
4. `privateSite` 会允许私有地址输出，必须只用于受控内网；公网客户端可能无法连接。
5. 订阅 token 放在 URL query 中，反向代理访问日志或客户端同步日志可能记录它。建议访问日志脱敏并使用专用受控订阅代理。
6. 关闭档案的 token 要求会让该档案链接公开可访问。只对适合公开发布的筛选档案关闭，并在重新开启时重新分发受保护链接。
7. TLS 健康探测只支持标准 TLS；Reality 做 TCP reachability；UDP/QUIC 为 `unverified`。无法由当前层证明节点可代理流量。
8. Komari route 凭插件权限共用现有服务器监听器；Fetch Metadata 反代兼容有本地测试，尚未在目标实例验证代理请求头配置。

## 验证证据

本地 Node 测试检查管理员策略、回调验证、单令牌轮换/撤销、幂等重试、NAT 映射冲突、口令加密导出往返解密、明文存储、订阅、原子备份和恢复；静态检查 `console` 日志不输出回调或订阅秘密。测试不是第三方审计，真实运行权限与部署路径仍待 AT 报告标记的目标环境验收。
