# 管理员操作手册

## 初始化

1. 在 Komari 插件管理器安装 ZIP，并批准 `node`、routes、system RPC 权限。
2. 打开 KNS 管理页。首次引导允许“稍后配置”并只读浏览；写操作仍被服务端锁住。
3. 设置 Agent 可访问的 HTTPS Komari 地址，核对 VLESS + Reality 默认模板。自动部署新探针默认关闭；如需启用，需单独勾选 root 安装授权。
4. 保存时 KNS 同步探针并记录既有 UUID 基线，不安装基线机器。随后创建默认订阅并显示链接；之后可从首页或订阅页再次查看。同步失败时引导保留填写内容且不标记初始化成功。
5. 插件原生生成 Clash/Mihomo、Loon、Surge/Surfboard、Quantumult X、Shadowrocket、Stash、V2RayN/V2RayNG、sing-box、SS 等订阅格式，不依赖外部 SubConverter。外部 SubConverter 默认关闭，仅用于额外 target；需要时显式配置受信 HTTPS 服务地址，不支持 HTTP。外部转换会收到订阅令牌与节点凭据，仅使用你信任的服务；清空地址并保存可关闭外部转换。Surge 不支持 VLESS Reality，VLESS 节点在 Surge/Surfboard 输出中会被跳过。
6. 如果探针使用私有/内网地址，在可信私网部署时启用“私有站点”；公开订阅默认拒绝私有、回环、保留和组播地址。
7. 先选一台在线测试探针检查机器名、地址、在线状态和 Agent 远程控制权限。远程安装权限默认开启；如果不希望某台机器可部署，可在该机器卡片取消勾选并保存。

## 新增节点

1. 打开“机器与节点”。机器顺序跟随 Komari 服务器列表；可切换三列卡片、单列卡片或紧凑列表，也可按在线状态、OneBox 检测情况、协议筛选。不纳管机器默认隐藏。远程安装权限默认开启，可直接在机器卡片勾选并保存以关闭单机权限。
2. 点击“安装新节点”，按“选择机器 → 选择协议 → 确认安装”操作。安装只会在管理员主动确认后提交；默认自动避开所选机器上的登记端口，需要时可手动调整。公网入口默认沿用机器 IPv4/IPv6 地址设置；选 NAT 时填写公网 IP/域名，并在每个协议的高级参数里填写公网外部端口。随后还要在路由器/云网络设备配置 `公网地址:外部端口/协议 → 机器地址:监听端口/协议` 转发；KNS 只记录映射，不会配置实际转发或防火墙。页面会显示连接地址预览，不同机器映射不同请分开安装。
3. 可选设置机器手动地址或 DDNS 域名。DDNS 使用 Cloudflare DNS over HTTPS 解析 A/AAAA；地址稳定两次后才登记。插件不会创建 DNS 记录。
4. 协议通过卡片多选。监听端口和 SNI 等参数放在卡片或高级设置中；VLESS Reality 的 SNI 由 OneBox 自动优选。监听地址高级项只提供 IPv4 或自动双栈，OneBox 当前接口不区分 IPv6-only 监听。
5. 确认前列出每台目标和连接地址，不会虚构远端端口检测结果。最多安装 10 台；多协议逐项提交，当前任务会在向导中显示真实状态，并同步显示在对应机器下。每组任务通过 Agent、OneBox 回调和远端状态核验后，才会继续下一协议；结果不确定时先核查同一任务。页面关闭后未提交的后续协议不会自动续跑。
6. 健康检测按实际 TCP/TLS 证据显示。只有 TCP 可达时不表示代理协议完整可用；UDP/QUIC 显示 `unverified`。

## 生命周期和发布

- **停止节点 / 启动节点**控制 OneBox 入站服务；不等于订阅隐藏。
- **从订阅隐藏 / 在订阅中显示**只改变发布状态，远端服务继续运行。
- **连接入口 / NAT**可在节点卡片修改订阅对外地址和公网外部端口。路由器/云网络的转发规则仍需单独设置，且传输协议与机器监听协议必须匹配。
- **卸载**会先做远端只读核查并显示资源归属、共享引用计数和服务影响，再要求最终确认；不会卸载共享 OneBox Runtime。状态预览缺失或不完整时，管理页会阻止卸载。
- **状态核查**是远端只读操作。
- **去重**会将配置完全相同的重复记录设为隐藏；不会卸载任何节点。

订阅节点名统一为“协议-机器名-端口”，例如 `VLESS-新加坡 · SG-01-443`；点击“新建订阅”会打开右侧抽屉，创建或编辑档案时可选择包含/排除机器、协议、标签、地址族、健康状态、输出格式和排序；输出格式包含原生客户端配置，订阅页也可按需切换客户端；机器与协议使用可搜索的多选器，选择后以标签显示；保存后也可编辑筛选。包含机器和排除机器同时设置时先限制到包含列表，再排除排除列表。标签是任一匹配。机器和协议选择留空表示全部。IPv4/IPv6 筛选会筛掉 Endpoint 中的其他字面地址，域名保留并交给客户端解析；双栈会保留所有已发布地址。每个档案只保留一个有效 token，默认要求令牌；创建时可关闭令牌要求，也可随时开启或关闭。关闭后任何拿到订阅链接的人都能读取匹配节点。令牌以明文保存在 KNS 状态中，管理页可重复查看；轮换会立即使旧 token 失效。关闭链接弹窗会清除本次页面内存中的令牌和链接。订阅 URL 等同于访问权限，不要发到公开位置。旧版只存 hash 的令牌无法回显，需轮换一次。

## 扫描历史 OneBox 节点

在“机器与节点”中点击“扫描已有节点”，或展开批量扫描选项后勾选在线机器批量提交。这是只读扫描，不会安装、修改或卸载配置。任务结果和可纳入节点会直接显示在对应机器卡片上；点击“纳入管理并加入订阅”即提交该节点，KNS 会通过 HTTPS 回调读取凭据并加密保存，不修改 OneBox 配置。页面不要求输入 2FA。可选展开节点的连接设置，调整公网地址或 NAT 外部端口；留空时使用机器地址策略和节点监听端口。纳入任务完成后，节点可进入符合筛选条件的已启用订阅。

扫描通过固定版本 OneBox KNS 适配器只读解析其可识别的 `/etc/onebox/config.json`。它不扫描任意代理程序或任意自定义路径。发现的节点只显示脱敏信息；多用户、协议参数不完整或当前适配器无法安全导出的节点会显示不支持，不会改写 OneBox 配置。

导出备份时输入独立口令并下载加密文件。KNS 不保存该口令；丢失后无法恢复文件。加密导出仍包含兼容旧密文的主密钥；明文 state 的凭据不依赖该密钥，但导出文件仍应按敏感数据保管。需要迁移或恢复时，在“数据恢复”选择加密文件并输入原口令；导入会替换当前 KNS 状态与密钥，开始前会留存本地恢复副本。使用 `KNS_MASTER_KEY` 环境变量时，目标环境必须预先配置相同的密钥。

## 地址优先级

实例 Endpoint 手动覆盖 > 机器手动公网地址 > DDNS 域名 > Komari 自动上报地址。NAT 外部端口作为节点监听端口的覆盖值；若管理员为该实例显式填写 Endpoint 端口，则实例覆盖优先。双栈 DDNS 使用 A/AAAA 解析结果拆分成独立节点；切换地址策略后需等待下一轮同步与连通性核查。地址变化时插件会重新检查相同公网地址、外部端口和 TCP/UDP 组合；出现冲突的实例会保留原 Endpoint、从所有订阅中排除，并在实例列表显示告警。解析到无冲突地址且通过连通性核查后，插件才恢复发布。

## 任务状态处理

- `dispatched` / `running`：查看 Agent 在线状态和 Komari 远程控制设置。
- `verifying`：远程任务完成，正在等待回调、status 核验或稳定 DDNS 解析。
- `needs_reconcile`：返回结构或两路状态不一致；不要盲目重装，先运行只读状态核查并检查目标机 OneBox 状态。
- `failed`：看退出码与错误码。插件不会保存远端输出全文，以免泄露凭据。
- `timed_out`：任务超过 30 分钟；在目标机核实运行状态后再用新的幂等键处理。
