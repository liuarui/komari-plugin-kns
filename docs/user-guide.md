# 管理员操作手册

## 初始化

1. 在 Komari 插件管理器安装 ZIP，并批准 `node`、routes、system RPC 权限。
2. 打开 KNS 管理页。首次引导允许“稍后配置”并只读浏览；写操作仍被服务端锁住。
3. 设置 Agent 可访问的 HTTPS Komari 地址，核对 VLESS + Reality 默认模板。自动部署新探针默认关闭；如需启用，需单独勾选 root 安装授权。
4. 保存时 KNS 同步探针并记录既有 UUID 基线，不安装基线机器。随后创建默认订阅并显示实际格式的一次性访问链接。同步失败时引导保留填写内容且不标记初始化成功。
5. 检查 SubConverter 服务地址和 target。创建或轮换订阅令牌时可切换当前服务支持的 target。外部转换会收到订阅 URI 与节点凭据；公网使用受信 HTTPS 服务。原生 KNS 订阅不依赖 SubConverter。
6. 如果探针使用私有/内网地址，在可信私网部署时启用“私有站点”；公开订阅默认拒绝私有、回环、保留和组播地址。
7. 先只允许一台测试探针，检查机器名、地址、在线状态和 Agent 远程控制权限。

## 新增节点

1. 在“探针”页显式启用目标机器的部署权限。
2. 在“节点”页按“选择探针 → 协议与网络 → 核对与提交”操作。`auto` 使用 Komari 可观察地址；`ipv4` / `ipv6` 要求对应地址；`dual` 保留双栈。若多台机器 NAT 映射不同，应拆分批次。
3. 可选设置机器手动地址或 DDNS 域名。DDNS 使用 Cloudflare DNS over HTTPS 解析 A/AAAA；地址稳定两次后才登记。插件不会创建 DNS 记录。
4. 选择协议、监听端口、监听地址和协议参数。监听地址是机器上的绑定地址；Endpoint/NAT 是客户端入口。需要 SNI 的协议才显示 SNI，VLESS Reality 的 SNI 由 OneBox 自动优选。
5. 最后一步列出每台目标的授权/在线预检。此处不探测远端端口。批量安装最多 10 台，任务会显示每台授权、Agent 派发、回调、远程状态核验和最终结果。提交受理不表示安装成功；结果不确定时先查同一任务。
6. 健康检测按实际 TCP/TLS 证据显示。只有 TCP 可达时不表示代理协议完整可用；UDP/QUIC 显示 `unverified`。

## 生命周期和发布

- **停用**会移除 OneBox 入站配置、保留 OneBox 实例登记和客户端凭据，并从订阅中过滤；再次启用会恢复配置。
- **隐藏**只设置 `publish:false`，远端服务继续运行；再次显示不会触发远程安装。
- **卸载**前必须在最近 5 分钟内完成远端状态核查。确认框会显示 OneBox 返回的资源归属、共享引用计数、防火墙处理和共享服务重载影响；状态预览缺失或不完整时，管理页会阻止卸载。
- **状态核查**是远端只读操作。
- **去重**会将配置完全相同的重复记录设为隐藏；不会卸载任何节点。

创建订阅档案时可选择包含/排除机器、协议、标签、地址族、健康状态、输出格式和排序；保存后也可编辑筛选。包含机器和排除机器同时设置时先限制到包含列表，再排除排除列表。标签是任一匹配。机器和协议选择留空表示全部。IPv4/IPv6 筛选会筛掉 Endpoint 中的其他字面地址，域名保留并交给客户端解析；双栈会保留所有已发布地址。每个档案可创建多个独立 token，便于为不同客户端分别发放和撤销；明文 URL 只在创建/轮换时显示一次。token 可单独撤销，档案撤销会一次性停用全部 token。轮换默认立即停用旧 token，也可配置最长 7 天宽限；轮换已撤销档案会创建新 token 恢复档案，旧 token 仍保持撤销。token 到期不会晚于档案到期。订阅 URL 等同于访问权限，不要发到公开位置。

## 批量扫描历史 OneBox 节点

在机器列表勾选在线探针，或点“全选在线探针”，再点“批量扫描所选旧版节点”。每批最多 100 台，插件最多同时提交 5 个扫描请求；离线探针会跳过，部分机器提交失败不会中断其他机器。任务提交成功不等于远端扫描完成，最终状态会出现在任务列表，扫描元数据会显示在机器行。

扫描通过固定版本 OneBox KNS 适配器只读解析其可识别的 `/etc/onebox/config.json`。它不扫描任意代理程序或任意自定义路径。发现的节点只显示脱敏信息；要纳入订阅仍须逐个确认，并填写公网 Endpoint/NAT 端口。多用户、协议参数不完整或当前适配器无法安全导出的节点会显示不支持，不会自动导入或改写 OneBox 配置。

导出备份时输入独立口令并下载加密文件。KNS 不保存该口令；丢失后无法恢复文件。备份包含恢复所需的主密钥，必须与口令分开保管。需要迁移或恢复时，在“数据恢复”选择加密文件并输入原口令；导入会替换当前 KNS 状态与密钥，开始前会留存本地恢复副本。使用 `KNS_MASTER_KEY` 环境变量时，目标环境必须预先配置相同的密钥。

## 地址优先级

实例 Endpoint 手动覆盖 > 机器手动公网地址 > DDNS 域名 > Komari 自动上报地址。NAT 外部端口作为节点监听端口的覆盖值；若管理员为该实例显式填写 Endpoint 端口，则实例覆盖优先。双栈 DDNS 使用 A/AAAA 解析结果拆分成独立节点；切换地址策略后需等待下一轮同步与连通性核查。地址变化时插件会重新检查相同公网地址、外部端口和 TCP/UDP 组合；出现冲突的实例会保留原 Endpoint、从所有订阅中排除，并在实例列表显示告警。解析到无冲突地址且通过连通性核查后，插件才恢复发布。

## 任务状态处理

- `dispatched` / `running`：查看 Agent 在线状态和 Komari 远程控制设置。
- `verifying`：远程任务完成，正在等待回调、status 核验或稳定 DDNS 解析。
- `needs_reconcile`：返回结构或两路状态不一致；不要盲目重装，先运行只读状态核查并检查目标机 OneBox 状态。
- `failed`：看退出码与错误码。插件不会保存远端输出全文，以免泄露凭据。
- `timed_out`：任务超过 30 分钟；在目标机核实运行状态后再用新的幂等键处理。
