安装节点

选择机器 → 选择协议 → 核对并安装。每一步只显示完成操作所需的信息。

1. 选择机器2. 选择协议3. 确认安装

可选择多个协议。端口会按目标机器已有节点自动避开冲突；提交前仍由服务端逐台检查。

在每个协议的“高级参数”中填写公网外部端口。还需在路由器或云网络中配置：公网地址:外部端口/协议 → 机器地址:监听端口/协议。KNS 只记录映射并生成订阅，不会修改 NAT 转发或防火墙。

选择机器和协议后显示连接地址预览。

高级设置

IPv4、IPv6 或双栈公网地址沿用机器网络设置；此处控制机器内服务的监听方式。OneBox 当前接口不区分 IPv6-only 监听。

任务进度和成功结果以 KNS 收到的 Agent、OneBox 回调与远端核查为准；“已提交”不代表安装完成。多协议按顺序执行，请保持此页打开直至结果显示；关闭后当前任务仍继续，但尚未提交的后续协议不会自动续跑。

订阅档案

先管理已有档案的令牌、格式和筛选；需要新档案时再使用下方表单。

新建订阅档案

关闭后链接无需令牌即可访问；任何拿到链接的人都能读取匹配的节点。

默认选择 URI 和 Mihomo 完整配置。没有服务端筛选预览接口；如筛选结果为空，创建后保留固定链接，节点数待状态核验。

每个档案只保留一个有效令牌。令牌会加密保存，之后可再次查看；轮换后旧链接立即失效。订阅 URL 含令牌，分享时请当作密码。

每种实际输出格式会在创建后单独提供复制，并可保存全部链接到本地文件。

服务与转换设置

令牌创建或轮换后，可在订阅结果中选择客户端。Clash 可选默认、ACL4SSR 轻量或完整规则模板（由当前 SubConverter 服务提供）；转换端会跳过目标客户端无法表示的协议。

KNS 回调要求 HTTPS 公网地址。外部 SubConverter 会收到原始订阅 URI 与其中的凭据；默认不启用外部转换，仅提供 KNS 原生订阅。需要转换时请显式配置可信 HTTPS 转换器；留空可关闭，不支持 HTTP。旧版保存的 HTTP 地址会被忽略，按空值处理。

OneBox 安装脚本固定到已审查的 Git commit 和 SHA256，不从可变 main 分支执行。

默认部署与新探针授权

默认模板只应用于首次发现的新探针。自动部署默认关闭；已派发任务不受开关变化影响。

数据恢复

每日保留 7 份状态和密钥备份。恢复前会校验状态与配对密钥；有未完成远程任务时会阻止维护。
