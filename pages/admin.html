安全边界

每台探针默认禁止自动部署。先为机器启用部署策略，再逐次确认具体任务；Komari Agent 必须以 root 运行。KNS 不创建 DNS 记录、不修改云安全组。

UDP / QUIC 协议的外部握手在当前插件约束下标记为 unverified；状态不会伪装成代理协议握手结果。

填写机器可以访问的地址，不要使用浏览器本机地址。格式检查不代表探针已验证可达。

SNI 由 OneBox 自动优选；模板只影响之后的新探针，既有节点不变。

开启后会在新探针上运行固定校验的 OneBox 安装器，可能修改代理配置与防火墙。首次同步的已有探针只建立基线，不会批量安装。

完成时先同步探针；同步失败会保留此表单并停止初始化。随后会创建默认订阅并显示一次性链接。

Komari 探针与部署策略

机器 UUID 是稳定关联键。部署策略默认关闭；旧版扫描只读检查 OneBox 配置，不会修改节点。可选择多台在线探针批量扫描；扫描结果脱敏显示，导入仍需逐个确认。地址来源顺序为实例地址、机器手动地址、DDNS 域名、Komari 上报地址。

部署 OneBox 节点

分三步选择探针、配置服务与网络、核对逐机结果。同一探针上的多个节点共用 OneBox sing-box Runtime。

1. 选择探针2. 协议与网络3. 核对与提交

监听端口是机器本地端口；Endpoint 与 NAT 外部端口是客户端连接入口。同一 Endpoint/NAT 覆盖会用于全部目标；映射不同请拆分批次。VLESS + Reality 的 SNI 由 OneBox 自动优选。

此处只做本地字段与逐机策略预检；不会预先探测远端端口。提交后仍需查看每台机器的 Agent、回调和远端状态核验结果。

新建订阅档案

默认选择 URI 和 Mihomo 完整配置。没有服务端筛选预览接口；如筛选结果为空，创建后保留固定链接，节点数待状态核验。

令牌只在创建或轮换时显示一次；服务器状态中只保存带盐哈希。每个档案支持多个独立令牌。订阅 URL 含令牌，分享时请当作密码。

每种实际输出格式会在创建后单独提供复制，并可保存全部链接到本地文件。

订阅档案

每个档案可管理多条独立令牌、格式白名单与节点筛选；轮换可设置 0–7 天宽限。

服务与转换设置

令牌创建或轮换后，可在订阅结果中切换已验证 SubConverter 服务支持的 target。转换端会跳过目标客户端无法表示的协议。

KNS 回调要求 HTTPS 公网地址。外部 SubConverter 会收到原始订阅 URI 与其中的凭据；当前默认 HTTP 会明文传输订阅令牌和节点凭据。公网使用前请配置可信 HTTPS 转换器。

OneBox 安装脚本固定到已审查的 Git commit 和 SHA256，不从可变 main 分支执行。

默认部署与新探针授权

默认模板只应用于首次发现的新探针。自动部署默认关闭；已派发任务不受开关变化影响。

数据恢复

每日保留 7 份状态和密钥备份。恢复前会校验状态与配对密钥；有未完成远程任务时会阻止维护。
